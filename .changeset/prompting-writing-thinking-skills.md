Add the `prompting`, `writing`, `thinking`, and `grill-me` skills. `prompting` covers text a model reads, including judge prompts. `writing` covers structure and content for prose a person acts on. `thinking` and `grill-me` cover pressure-testing a plan and mapping code before building. The Claude Code package now ships an empty Cursor manifest, so Cursor no longer lists every skill twice when both plugins are installed.
