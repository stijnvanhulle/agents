Add the `prompting`, `writing`, and `thinking` skills. `prompting` covers text a model reads, including judge prompts. `writing` covers structure and content for prose a person acts on. `thinking` covers mapping code and reshaping code that resists change before building. The Claude Code package now ships an empty Cursor manifest, so Cursor no longer lists every skill twice when both plugins are installed.
