# Jira issues

- Story: a persona and acceptance criteria a tester can check one by one, one behavior each.
- Bug: steps and the actual behavior. Epic: the goal and its related stories.
- Split work that does not fit a sprint. A one-off fix is never an epic.
- Create and edit with `createJiraIssue` and `editJiraIssue`, and link the ticket references.
- Put payloads in fences. Type inline backticks in Jira's editor and check the result.
